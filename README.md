# Unit 10 – Group JavaScript Workshop

Duration: 3 hours

## Goal

You will work in groups to **analyse, fix, and extend an existing JavaScript project**.

This simulates real developer work where you often work with code written by someone else.

---

# Part 1 – Run the Project

Open the starter project and run it with Live Server.

Explore:

* adding tasks
* refreshing the page
* adding many tasks

Discuss with your group:

What problems do you notice?

---

# Part 2 – Identify Bugs

Look inside script.js.

Try to find problems such as:

* duplicate tasks appearing
* tasks not clearing input
* empty tasks allowed
* list not refreshing correctly

Fix the bugs as a team.

---

# Part 3 – Improve the Application

Choose at least **two improvements**.

Ideas:

* prevent empty tasks
* allow Enter key to add tasks
* add delete buttons
* improve styling
* add a task counter

---

# Part 4 – Redesign Challenge

Optional group challenge:

Redesign the interface.

Ideas:

* dark theme
* completed tasks
* better layout

---

# Part 5 – Peer Review

Swap projects with another group.

Review:

* Does it work correctly?
* Is the code readable?
* Are variables named clearly?
* Is the UI easy to use?

Provide feedback.

---

# Part 6 – GitHub Etiquette

Discuss:

* writing good commit messages
* creating issues
* reviewing pull requests
